How this makes the next read better

THE NOISE: 1 defensive touchdown, the spread result changed on the final score, 1 non-offensive or return score. Whatever the scoreboard says, none of that is a repeatable property of either team, and weighting it in the next look at these sides would be learning the wrong thing.

THE SIGNAL TO RE-EXAMINE: scoring and passing. EdgeDesk rated it one way and the game showed the other. One result does not settle it — the question is whether the same category has been contradicted before, which is what the research-lesson store is for.

THE ASSUMPTION THAT CANNOT BE CHECKED: 3 of the claims in the original article rest on signals no box score in this repository publishes. Those parts of the number are carried on faith between one model rebuild and the next, and it is worth knowing which parts those are.
