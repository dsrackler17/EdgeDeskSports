# Sports inventory for the CLV programme

**Written:** 2026-10-21 (Step 0, before any CLV result was computed).
**Repo state:** branch `claude/peaceful-cerf-454kmq` at `35225a09`.
**Scope:** every sport that has a model, or had one, anywhere in the repo.

**Sources:**
- `engine/registry.json`
- `docs/model-loop/*/versions.json`
- each sport's `live.json` / `params.js`
- the committed slates
- four read-only surveys of the code (football, hockey/NBA, the other sports, and every odds archive)

**Season labels:** the repo labels NBA, NHL and college basketball seasons by their **end** year (2026 = 2025-26). Football, MLB, WNBA and UFC use the calendar year. This document uses the repo's labels.

## Order of work (in season and line data first)

1. **CFB.** In season, and the deepest opener archive. The mandated holdout (2025 + 2026) has openers.
2. **NFL.** In season. Openers 2011-2021; the holdout has 2026 openers only.
3. **NBA.** Season opened 2026-10-20. Openers for 2012-2022, and DraftKings open/close for the 2026 holdout.
4. **NHL.** In season. Openers for 2012-2022; the holdout has no openers.
5. **MLB.** Postseason. Openers for 2011-2021; the holdout has no openers.
6. **WNBA.** Finals. Openers exist only in the holdout season.
7. **NCAAM.** Opens 2026-11-02. Openers exist only in the holdout season.
8. **NCAAW, UFC, college baseball, tennis.** No line data. Phase 1 only; every later phase is documented as infeasible.
