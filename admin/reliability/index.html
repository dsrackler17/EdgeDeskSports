CFB reliability diagnostics

Development view

Reliability is a 0–100 score for how much EdgeDesk can trust the completeness, freshness, consistency and stability of the information under each college projection. It is not a probability that a projection is right, and it is not a betting signal. It is built from six components with hard caps. This page shows where it is being lost across the slate.
