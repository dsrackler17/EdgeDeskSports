# Source access and rights

The source feed is ESPN public factual API responses, normalized to game/event/boxscore records. Endpoints are undocumented; commercial access/redistribution rights and API stability are not certified. Source URL, response digests, capture time and collection failures are recorded. This is a research asset; do not assume product-feed rights from public accessibility.

Native NHL play-by-play, shift charts, team summaries and club schedules were tested again and returned HTTP 403. No blocked access was bypassed.

MoneyPuck's current data page grants noncommercial use and ad-hoc journalism; other use requires contacting the provider. No MoneyPuck data was copied into this commercial-project package. Source: https://moneypuck.com/data.htm

NHL EDGE offers public tracking summaries; a bulk commercial data license/export is not inferred. Source: https://www.nhl.com/nhl-edge/teams/

Historical publication timestamps are not reconstructed. Cached files from the previous package can have unknown retrieval time in this new manifest; we retain response digests and do not backdate knowledge.
