Keep rule: SELECT log loss at least 0.0005 below the model before the step, and FIT log loss no worse. Promotion rule: TEST log loss at least 0.0005 below 1.1.0's on the same bouts with the card-blocked paired 95% interval below zero, and the Brier score no worse.
