EDGEDESK INTELLIGENCE — THE SIX-QUESTION SEQUENCE, THROUGH THE REAL SERVER PATH
==============================================================================

Regenerate:  npm run intel:chat          (tools/intelligence/conversation.js)
Asserted by: node tools/intelligence/conversation.test.js

WHAT IS REAL HERE
  The deployed edge function, imported and driven exactly as app.html drives it:
  same POST body, same growing history array, same board scope. Auth, intent
  classification, conversational state, staged retrieval, eligibility, evidence
  packets, the deterministic decision pass, prompt assembly, the response path,
  the ledger write and the client renderers are all the shipped code. The FBS
  slate and the availability artifact are the real committed files; the database
  is fixtures, because there is no live Supabase in CI.

WHAT IS NOT
  The model's own words. This environment has no Anthropic credential and no
  egress to the deployed function, so inference is stubbed at the HTTP boundary.
  The prompt that would reach it is captured verbatim; the text a real Claude
  would write is not produced here and is not claimed.
