How Signal Center decides

  • Only comparable numbers. The same event, the same outcome, the same model and the same market definition — or no signal.
  • The evidence ladder. Confirmed cause needs a calculation that isolates one input. A dated event between two snapshots is a supported association. Otherwise the movement is unexplained, and Signal Center says it does not know yet.
  • Model changes are labelled. A move across a new model version is reported as a methodology change, not as new information about the game.
  • Markets, honestly. A named sportsbook, a recent capture time, a two-way price with the margin removed, and the teams in the right order. A disagreement is a question to research, never a recommendation.
  • Model DNA. Every signal carries the model’s live record: calibration, Brier score and log loss against real results, and how it compares with the market on the same games. Raw win rate is not a measure of model quality and is not shown as one.
  • History is kept. A correction is a new version; a withdrawal keeps every earlier version readable.

Signal Center starts with NFL and college football. Where a sport has no dated source for a kind of signal, it says so instead of filling the gap. The full rules are in EdgeDesk’s methodology.
